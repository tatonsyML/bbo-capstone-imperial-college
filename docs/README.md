# Documentation guide

Choose the level of detail you need. Each page has a distinct purpose so the main README stays approachable.

| Reader | Document | What it answers |
|---|---|---|
| Everyone | [README](../README.md) | What was the challenge and what happened? |
| Everyone | [Function-by-function guide](function_guide.md) | Which input did best, why, and what is uncertain? |
| Everyone | [Project journey](project_journey.md) | How did the approach change from Round 1 to Round 12? |
| Technical reader | [Strategy and validation](strategy_and_validation.md) | Why GP/EI/UCB, challengers, calibration and structural models? |
| Technical reader | [Structural reconstruction](structural_reconstruction.md) | Which equations are supported, and how strongly? |
| Auditor | [Round 12 evidence](round12_evidence.md) | Which outcomes and prospective predictions were actually confirmed? |
| Auditor | [Provenance](evidence_provenance.md) | What originated with the course, this participant or external publications? |
| Auditor | [Decision log](decision_log.md) | How did evidence affect important query decisions? |
| Reproducer | [Run and reproduce](reproduce.md) | Which code is checked and what remains historical? |
| Researcher | [Model card](model_card.md) · [Datasheet](datasheet.md) | Full modelling and dataset documentation |

## Two clear reading sequences

**Short route (about the argument):** [README](../README.md) → [function guide](function_guide.md) → [project journey](project_journey.md) → [main retrospective](../submissions/stage_2/component_25_1/retrospective.md).

**Technical route (about the evidence):** [model card](model_card.md) → [validation strategy](strategy_and_validation.md) → [reconstruction](structural_reconstruction.md) → [reproduction](reproduce.md) → [provenance](evidence_provenance.md).
