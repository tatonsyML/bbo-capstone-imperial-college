# Programme-supplied initial data

The original capstone seed arrays are retained in the working project but are not redistributed in this public repository until the programme's redistribution terms are confirmed.

The datasheet records their provenance and observation counts. The accumulated CSV files preserve the full observation history used for Module 21 analysis while marking programme-supplied rows separately from later portal queries.

If redistribution is confirmed, place `initial_inputs.npy` and `initial_outputs.npy` under `data/initial/function_1/` through `data/initial/function_8/`.
