# Course-provided initial observations

The original `initial_inputs.npy` and `initial_outputs.npy` files are **not hosted in this repository**.

However, their **175 numeric observations are present** in [the consolidated CSV](../all_observations.csv), with `source=course_initial` and `is_initial=True`, and in per-function historical CSVs. Thus, **the numerical values themselves are publicly redistributed**, even though the source binary arrays are absent. Earlier documentation did not make this distinction clear.

**Permission has not been independently verified.** Before treating the numerical values as freely reusable, confirm the course's redistribution terms. If the course prohibits public redistribution, remove the course rows from the public release and provide an authorised route to obtain them, updating notebook instructions accordingly.

The 104 personal submitted-query returns remain clearly distinguished from course-provided starting points. See the [final datasheet](../../docs/final_datasheet.md).
