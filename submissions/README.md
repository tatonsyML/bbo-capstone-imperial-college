# Capstone Submission Archive

This area preserves assessment-facing capstone material separately from the living project.

## Rule

- `submissions/` preserves recoverable assessment snapshots and provenance notes.
- `docs/`, `reports/`, `src/`, `data/` and `experiments/` represent the evolving project.
- A historical submission is copied here only when the exact final text or file is recoverable.
- If the exact submitted version cannot be verified, the folder records that limitation instead of reconstructing or inventing a submission.
- A final draft is not labelled "submitted" unless submission itself is confirmed.

## Query-round evidence

The numerical query/output submissions are preserved independently in [`experiments/`](../experiments/). Those folders are the authoritative round-by-round record of what was queried and what the portal returned.

## Future workflow

For each future assessed component:

1. Work in the living repository.
2. Freeze the exact assessment version only when it is final.
3. Copy it into the relevant `submissions/` folder.
4. Record the evidence cut and submission status.
5. Continue updating the living project without changing the frozen snapshot.

This prevents later improvements from rewriting the historical record.
