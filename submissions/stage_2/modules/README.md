## Preservation rule

Original participant-created artefacts are copied unchanged where they survive. Programme-supplied seed arrays and source ZIPs are not republished in this public repository until redistribution rights are confirmed.

Where no standalone original package survives, the folder contains a **recovered evidence pack** built only from the exact historical portal query/output records already preserved in the project. It is labelled as recovered evidence, not misrepresented as the original submitted package.
