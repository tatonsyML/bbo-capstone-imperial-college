# Thirteen portal rounds | the experimental record

Each round folder contains the submitted query values, returned portal scores and, where retained, the reasoning for the next experiment. **A portal return is an observation; a model forecast is not.** For R1–R7, explanations have been written retrospectively and link to surviving coursework rather than claiming to be contemporaneous notes.

| Round | Record | What the returned evidence taught me |
|---|---|---|
| 1 | [R1](round_01/) | An initial GP/UCB baseline was insufficient for functions with sharply different scales |
| 2 | [R2](round_02/) | F4 and F5 improved; candidate predictions still needed confirmation |
| 3 | [R3](round_03/) | Five functions improved, strengthening the case for function-specific policies |
| 4 | [R4](round_04/) | Alternative-model and local-probe diagnostics broadened the evidence |
| 5 | [R5](round_05/) | Controlled refinements improved F4, F5, F7 and F8 |
| 6 | [R6](round_06/) | F2 and F3 advanced; F6 showed the limits of a confident local policy |
| 7 | [R7](round_07/) | F5 and F7 improved, but F1 remained close to zero |
| 8 | [R8](round_08/) | Pre-result forecasts tested against returned outputs; model agreement remained uneven |
| 9 | [R9](round_09/) | F4's forecast was exceptionally accurate locally, while F2 missed substantially |
| 10 | [R10](round_10/) | F5 reached the permitted upper corner and F8 reached the quadratic vertex |
| 11 | [R11](round_11/) | F1 and F2–F4 reached new bests after exploring different regions |
| 12 | [R12](round_12/) | F6 improved and F7's structural prediction matched to numerical precision |
| 13 | [R13](round_13/) | Final new records for F2, F3 and F4; the other five did not improve |

The [full 279-row record](../data/all_observations.csv) contains 175 initial course observations and 104 personally returned scores. F7's R11 output was preserved but its input coordinates were not, so no location has been invented.
