# Usage, attribution and course data

This repository is public to support course assessment, reproducibility and portfolio review.

**Source code:** No open-source software licence has been selected. Public availability alone does not grant a licence for unrestricted reuse. Contact the repository owner if you need permission for reuse outside normal reading and academic review.

**Course-provided data:** The original programme-provided NumPy binaries are not hosted, but the **175 numerical starting observations are included** in the public [consolidated CSV](data/all_observations.csv) and historical per-function CSVs. Redistribution terms for those values are **not yet verified**. Please do not assume those values are licensed for external redistribution, even though they are publicly accessible.

**Original observations:** The 104 personal portal returns are separately identified. Mathematical reconstructions and retrospective HEBO/TuRBO benchmark simulations are not the same as genuine new portal observations.

**External evidence:** Publicly shared peer observations used during analysis remain external research evidence and are not included in the personal-return count.

The course's data-sharing policy should be confirmed before a permanent public release tag is created. See the [final datasheet](docs/final_datasheet.md) and [evidence provenance](docs/evidence_provenance.md).
