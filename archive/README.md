# Older material and supporting evidence

[← Project homepage](../README.md)

The **main reading experience** is [the eight function stories](../functions/README.md). This section keeps older working material, course-era notes and supplementary experiments accessible without making them the entry point.

### Historical sources

- [Original round files, R1–R13](../journey/README.md): returned values, notebook versions, preserved scripts and round context. Their provenance is retained even where a selection script was lost.
- [Data snapshots](../data/accumulated/): earlier observations and score histories retained to reproduce chronological decisions.
- [Older decision log](notes/early_decision_log.md) and [project timeline](notes/early_project_timeline.md): useful historical viewpoints that may not reflect the final 13-round results.
- [Legacy coursework checklist](coursework/legacy_checklist.md): superseded documentation, preserved only as historical context.
- [Post-capstone comparison research](../research/full_optimisers/README.md): later full HEBO and TuRBO-1 reference implementations, not original historical query generators.

### What is canonical now?

For results, use **[data/all_observations.csv](../data/all_observations.csv)**. For chronological explanations, use the function stories and original `journey/` evidence. For models, use the [model card](../MODEL_CARD.md). The public README intentionally does not list every draft and CSV snapshot.
